本模块是独立于 ESP32 固件和 desktop_bot 主进程的集成层，包含两个互补的事件桥接实现：
- `log_event_bridge.py`：作为 sidecar 进程运行，通过 `--log` 参数 tail 指定日志文件（默认 `logs/perception.log`），按 `perception event {json}` 标记行解析并 POST 到网关，支持 `--from-start` 从头读取。
- `web_event_forwarder.py`：可复制到 desktop_bot 仓库内直接 import 的异步封装类 `WebEventForwarder`，在 `EventCache.append()` 后调用 `await forwarder.send(event)` 即可发送结构化事件。
两者共享同一目标端点 `http://127.0.0.1:18000/api/v1/perception/events`，均要求 HTTP 202 响应，失败时抛出 `RuntimeError`；PCM/JPEG 等大帧数据不转发，仅传递结构化 JSON。依赖方向单向指向外部 Web 网关，不反向依赖 desktop_bot 或 AI Hub OS 内部实现。
