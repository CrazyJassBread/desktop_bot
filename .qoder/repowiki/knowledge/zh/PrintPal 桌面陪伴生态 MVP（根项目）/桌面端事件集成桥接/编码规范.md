- 所有对外部网关的请求统一使用 `urllib.request.Request` + `urlopen` 发起 POST，Content-Type 固定为 `application/json; charset=utf-8`，且仅接受 HTTP 202 状态码，否则抛出 `RuntimeError`。
- 事件负载通过 `ensure_ascii=False` 序列化为 UTF-8 JSON，避免中文等字符被转义。
- 超时时间默认 3.0 秒并通过构造函数或命令行参数显式注入，便于测试与调优。
- 模块顶部使用 `from __future__ import annotations` 启用 PEP 563 延迟求值注解。
