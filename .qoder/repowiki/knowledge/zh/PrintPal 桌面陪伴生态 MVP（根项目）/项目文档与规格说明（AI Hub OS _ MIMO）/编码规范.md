- 所有跨服务接口以 OpenAPI 3.1 文件（`openapi.yaml`）为唯一权威来源，前端通过生成客户端消费，禁止手写 URL 前缀。
- 文档按数字编号目录（01_Product → 10_Development_Log）组织，每个领域独立成文件，便于按阶段演进与检索。
- 端口分配集中维护在《端口与服务注册表.md》，新增服务必须登记且不得与保留端口冲突。
- 敏感信息（密码、令牌、API Key、ESP32 IP）严禁出现在日志与文档中，统一通过环境变量或安全 Cookie 传递。
- 打印链路强制遵循“浏览器 → 平台 API → Device Gateway/ESP32 → 热敏打印机”，前端不得直连设备 IP。
