根目录作为多语言聚合工程：Node.js 侧通过 package.json 管理 Web MVP（端口 18000），Python 侧通过 requirements.txt 管理 desktop_bot 持续感知服务（端口 8090/8080/8081），两者通过 HTTP/WebSocket 契约通信——desktop_bot 暴露 /api/events 事件流与 /api/results 结果提交，Web 端调用 AI Hub OS 网关 /api/v1/photos/hardware 等接口；config.yaml 集中定义音频、ASR、VAD、关键词、视觉、应用与 API 参数，.env.example 提供 DeepSeek 与 ESP32 打印机环境变量模板；pytest.ini 将 tests 目录注册为测试入口，scripts_and_tools 提供 ESP32 外设调试脚本，docs_and_specs 沉淀产品与架构文档，形成“Web 前端 + Python 感知后端 + ESP32 硬件 + 文档/测试”的统一开发闭环。
