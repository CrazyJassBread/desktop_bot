- 所有运行时参数集中在 config.yaml 中按 audio/asr/vad/keywords/perception/vision/application/api 分段声明，代码仅读取不硬编码。
- Python 服务通过 aiohttp 暴露 REST + WebSocket 双协议 API，统一在 /api/* 路径下，健康检查固定为 GET /api/health。
- ESP32 硬件接入遵循 TCP PCM（8080）与 HTTP JPEG（8081）两种标准协议，由 hardware 配置段统一开关与端口管理。
- 测试用例按功能域分文件存放于 tests/ 目录，使用 pytest markers（如 live）区分需外部依赖的测试。
