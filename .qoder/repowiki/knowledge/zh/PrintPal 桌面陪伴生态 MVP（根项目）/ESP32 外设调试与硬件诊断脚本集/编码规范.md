- 每个脚本都暴露 `main()` 函数并通过 `if __name__ == "__main__": main()` 作为 CLI 入口，CLI 参数统一使用 `argparse.ArgumentParser` 定义。
- 对外部 HTTP 请求统一使用 `requests.post(..., timeout=...)` 并调用 `response.raise_for_status()` 抛出异常，错误信息通过 `print` 输出状态码与响应体。
- 需要可选重型依赖（如 cv2、numpy）时采用运行时 `import` 并在 ImportError 中抛出带明确安装提示的 RuntimeError，避免模块级导入失败。
- 文件与目录操作统一使用 `pathlib.Path`，输出目录通过 `mkdir(parents=True, exist_ok=True)` 创建，文件名采用固定前缀加四位序号格式（如 `el_XXXX.wav`）。
