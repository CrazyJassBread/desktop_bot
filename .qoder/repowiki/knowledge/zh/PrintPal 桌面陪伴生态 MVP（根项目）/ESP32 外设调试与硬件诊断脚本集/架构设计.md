本模块由两个并列的 Python 包组成：`scripts/` 和 `tools/`，每个文件都是可独立执行的 CLI 工具（通过 `if __name__ == "__main__": main()` 入口）。
- `scripts/printer_test.py` 与 `tools/printer_test.py` 功能重复但实现不同：前者使用 JSON 与 GB2312 两种编码路径并支持更多排版参数，后者是精简版；二者均通过 HTTP POST 调用 ESP32 的 `/printer/text` 与 `/printer/feed` 接口。
- `scripts/receive_images.py` 基于 `app.transport.hardware_sources.HTTPJPEGImageSource` 异步监听 8082 端口，将 JPEG 帧写入 `received_images/` 目录用于固件诊断。
- `scripts/receive_microphone.py` 使用标准库 socket + wave 模块在 8081 端口接收 PCM 流并保存为 `microphone.wav`。
- `scripts/record.py` 基于 `sounddevice` + `soundfile` 实现交互式 WAV 录音，按 `el_XXXX.wav` 命名并维护 `records/metadata.csv` 元数据。
- `scripts/vision_live.py` 复用 `app.factories.build_gesture` 与 `ContinuousVisionProcessor`，通过 OpenCV 窗口实时显示手势检测结果。
依赖方向单向指向 `app.*` 内部模块（配置加载、硬件源、视觉处理），本模块不反向被业务代码引用。
