# 2026-07-23 智能桌面伴侣前端重构

## 背景

产品方向从“AI 硬件创作者社区工作台”切换为“ESP32-S3 + AI Agent + 打印交互的
智能桌面伴侣”。用户明确要求放弃旧前端，先看到不依赖数据库的硬件与系统应用 MVP。

## 本次完成

- 删除旧社区型前端页面和旧 Mock Platform；
- 建立 MIMO 视觉系统、响应式 App Shell 和 10 个路由；
- 实现 Dashboard、登录/注册、教育、娱乐、生活、信件、设备、自动化和设置；
- 实现 AI Tutor、单词卡、Cloud Runner、海龟汤、OCR 演示、彩蛋、手帐总结、
  趣味签、AI Letter 和笔友卡；
- 实现录音、拍照、打印、语言、游戏、同步、唤醒、睡眠、重启和软关机；
- 实现 FSM、打印任务、DeviceBus v1、ACK/heartbeat/reported state；
- 重做独立 MIMO One 设备模拟器，模拟屏幕、摄像头、打印机与手势；
- 保持数据库未接入，状态使用 LocalStorage；
- Web 继续占用 `18000`，没有消费后续预留端口。

## 技术决策

当前环境无法可靠访问 npm registry，因此先用原生 ES Modules 交付可运行 MVP，
同时按 Next.js feature 结构设计模块边界。生产迁移目标仍为 Next.js/React/TypeScript，
不把本轮零依赖实现视为最终技术栈。

## 保留与替换

- 保留：文档目录、端口注册表、DeviceBus 消息信封、部署演进方向；
- 替换：社区导航、社区内容模型、旧 Dashboard、旧联动实验室；
- 延后：数据库、多用户真实认证、真实 LLM/OCR、MQTT Broker、ESP32 固件接入。

## 下一步

1. 将 DNESP32S3 固件与 `device.message.v1` 对齐；
2. 先打通 heartbeat、设备影子和一个像素屏命令；
3. 接入真实热敏打印机并处理缺纸/过热错误；
4. 增加局域网配网与一次性绑定码；
5. 部署 18010 API、18020 Realtime、18200 Device Gateway；
6. 再接 PostgreSQL、用户认证和长期任务日志。
