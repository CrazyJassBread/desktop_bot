## 已接受的关键决策

1. MVP 先社区，不把在线 Agent 和设备接入混进首期。
2. 核心后端从模块化单体开始，而不是微服务集群。
3. Voice Runtime 作为独立服务演进，复用现有 Python 代码。
4. MQTT 承担设备长连接控制；大音频/固件走 HTTPS/S3。
5. 文件公开前必须异步扫描，上传由客户端直传对象存储。
6. Agent 真实写操作、设备动作默认需要审批和最小 scope。
7. 生产数据库迁移采用 expand/contract，部署不能手工改服务器。
