# 2026-07-23 无数据库联动 MVP

## 用户决策

- 数据库暂缓；
- 优先看到硬件、Agent 与系统应用联动的可运行产品；
- 后续再接 PostgreSQL、真实 Agent Runtime 与 ESP32-S3。

## 本次交付

- 零第三方运行时依赖的响应式 Web 应用；
- 社区发现、搜索、互动和本地发布；
- Agent 工坊、任务运行状态和运行历史；
- 设备中心、Device Shadow 和远程控制；
- 手机端固定快捷遥控条；
- 运行、联网睡眠、重启、软关机电源状态机及物理唤醒限制；
- 手势事件协议与挥手、手掌、点赞、双击模拟；
- 独立硬件模拟器；
- 主系统/模拟器双向握手、心跳、命令、ACK、状态上报；
- 语音意图 → ASR 模拟 → Agent 路由 → Policy → 设备动作 → 回复；
- 浏览器 LocalStorage 持久化和演示数据重置；
- 健康检查、生产构建、领域单元测试和真实浏览器 QA。

## 当前边界

- 社区、用户和运行记录不在服务器持久化；
- Agent/ASR/TTS 是可演示的确定性 Mock；
- 硬件是独立浏览器设备模拟器，不是真实 ESP32 固件；
- 多浏览器、跨网络、权限和数据一致性需在接入后端后实现；
- Sites 创建请求遇到连接层错误，本轮没有生成生产站点 ID。
