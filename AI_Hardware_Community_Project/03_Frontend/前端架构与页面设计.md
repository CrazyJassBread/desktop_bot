# 前端架构与页面设计

## 1. 技术基线

| 类别 | 选择 | 用途 |
|---|---|---|
| 框架 | Next.js 15+ App Router、React、TypeScript strict | SSR/ISR、SEO、路由 |
| 样式 | Tailwind CSS + CSS Variables | Token 化主题与响应式 |
| 组件 | shadcn/ui + Radix primitives | 可访问的基础组件，不锁定黑盒库 |
| 服务端状态 | TanStack Query | 缓存、失效、乐观更新 |
| 客户端状态 | Zustand（仅必要时） | 编辑器草稿/UI 状态 |
| 表单 | React Hook Form + Zod | 前端体验校验；服务端仍须校验 |
| 编辑器 | Tiptap 或 Markdown 双模式 | 文章/项目 README |
| API 客户端 | OpenAPI 自动生成 | 防止手写 DTO 漂移 |
| 测试 | Vitest + Testing Library + Playwright | 单元、组件、E2E |
| 观测 | OpenTelemetry Web + 错误上报 | Web Vitals、异常与 trace |

原则：Server Component 默认，只有交互、浏览器 API 或局部状态需要时才加 `"use client"`。不要把所有页面做成 SPA。

## 2. 信息架构与页面

### 公共区

| 路由 | 页面 | 关键内容 |
|---|---|---|
| `/` | 首页 | 推荐/最新、精选项目、热门标签、创作者 |
| `/explore` | 发现 | 类型、分类、标签、时间、排序筛选 |
| `/search?q=` | 搜索 | 内容/用户/Agent 分栏、筛选、纠错 |
| `/c/[slug]` | 内容详情 | 正文、作者、资源、互动、评论 |
| `/projects/[slug]` | 项目详情 | README、硬件、许可证、资源/Release |
| `/agents/[slug]` | Agent 展示 | 介绍、版本、权限、示例、评价（Phase 2 运行） |
| `/u/[username]` | 用户主页 | 资料、作品、项目、收藏、关注 |
| `/categories/[slug]` | 分类 | 分类说明与内容流 |
| `/tags/[slug]` | 标签 | 标签内容和相关标签 |
| `/guidelines` | 社区规范 | 内容、版权、安全与申诉 |

### 认证区

`/login`、`/register`、`/verify-email`、`/forgot-password`、`/reset-password`。登录后若原请求需要认证，应安全返回原路由；只允许站内相对路径，防开放重定向。

### 创作者工作台

| 路由 | 能力 |
|---|---|
| `/studio` | 数据概览、草稿、近期评论 |
| `/studio/new` | 选择动态/文章/项目/Agent |
| `/studio/content/[id]/edit` | 编辑、自动保存、预览、发布 |
| `/studio/assets` | 文件、配额、引用关系 |
| `/studio/analytics` | 浏览、收藏、下载趋势 |
| `/studio/agents/*` | Agent Builder/版本/运行（Phase 2） |

### 用户设置

`/settings/profile`、`/settings/account`、`/settings/security`、`/settings/notifications`、`/settings/privacy`、`/settings/devices`（Phase 3）、`/settings/api`（Phase 4）。

### 管理后台

`/admin/overview`、`/admin/users`、`/admin/content`、`/admin/reports`、`/admin/files`、`/admin/taxonomy`、`/admin/audit`、`/admin/system`。后台布局与公共站点分开，敏感操作要求重新认证和填写原因。

## 3. 页面布局

### 全局 Shell

- 顶栏：Logo、全局搜索、发布入口、通知、用户菜单；
- 桌面侧栏：发现、项目、Agent、关注；
- 移动端底栏：首页、发现、发布、通知、我的；
- 全局层：登录弹窗、确认对话框、上传队列、Toast。

### 内容详情

```text
┌──────────────── 顶栏 ────────────────┐
│ 面包屑 / 类型 / 状态                  │
│ 标题、摘要、作者、发布时间、统计       │
├──────────── 主内容 ───────┬──────────┤
│ 正文 / README / 资源       │ 作者卡片 │
│ 版本与兼容性               │ 目录     │
│ 评论                       │ 相关内容 │
└───────────────────────────┴──────────┘
```

小屏将右栏折叠到正文后，互动工具栏固定在底部但不得遮挡内容。

## 4. 组件分层

```text
ui/           Button, Dialog, Input, Tabs, Skeleton
shared/       Avatar, MarkdownRenderer, FilePreview, EmptyState
features/     auth, content, comments, upload, search, notifications
entities/     UserCard, ContentCard, AgentCard, DeviceCard
widgets/      Header, Feed, CommentThread, Editor, AdminTable
app routes/   页面装配与数据获取
```

领域组件不直接调用 `fetch`；数据请求放在 feature 的 query/mutation 层。`ui` 不引用业务模块。

## 5. 状态管理

- URL：搜索词、筛选、排序、分页，确保可分享和前进后退；
- Server Component：首屏和 SEO 数据；
- TanStack Query：登录后的列表、互动状态、通知、后台数据；
- React Hook Form：表单临时状态；
- Zustand：跨组件上传队列、复杂编辑器会话；
- IndexedDB：仅保存未发布草稿和断网待重试，不存认证令牌。

缓存 key 规范示例：

```ts
contentKeys.all
contentKeys.list({ type, tag, sort, cursor })
contentKeys.detail(id)
contentKeys.comments(id, sort)
```

点赞乐观更新失败必须回滚；发布、删除、权限修改等高影响操作等待服务端成功再展示最终状态。

## 6. 编辑与上传体验

- 30 秒或内容变更后防抖自动保存，携带 `version` 做乐观并发控制；
- 冲突返回 409，显示“服务器版本/本地版本”，不静默覆盖；
- 图片粘贴和拖拽进入上传队列，扫描完成前显示处理中；
- 离开未保存页面弹窗提示；
- Markdown 渲染禁用原始 HTML 或经白名单消毒；
- 项目发布前展示完整度检查：许可证、硬件、版本、说明、资源安全状态。

## 7. 权限和错误体验

- Middleware 只做粗粒度路由门禁，真正授权由 API 完成；
- 401：静默刷新一次，失败后回登录；
- 403：说明缺少的权限或资源不可见；
- 404：不泄露私有资源是否存在；
- 409：展示冲突解决；
- 422：字段级错误；
- 429：展示可重试时间；
- 5xx：友好错误、request ID、重试入口。

## 8. SEO、性能与无障碍

- 内容详情 SSR/ISR，动态 `metadata`、canonical、OpenGraph；
- 项目/文章增加 JSON-LD（Article/SoftwareSourceCode，按实际类型）；
- sitemap 分片，草稿/私有/下架内容不进入；
- 图片 AVIF/WebP、多尺寸、懒加载，首屏 LCP 图预加载；
- Bundle 分析，编辑器/图表按需加载；
- 目标：LCP <2.5s、INP <200ms、CLS <0.1（P75）；
- 键盘可操作、可见焦点、语义标签、表单错误关联、颜色对比至少 WCAG AA；
- `prefers-reduced-motion` 降低动画。

## 9. 前端安全

- 不把 Access Token 放 LocalStorage；使用安全 Cookie 策略；
- 所有富文本用服务端与客户端双重消毒；
- 严格 CSP，脚本 nonce，禁止不必要第三方脚本；
- 敏感表单 CSRF 防护；
- 外链使用 `rel="noopener noreferrer"`；
- 上传预览不执行 SVG/HTML；不可信 SVG 先转码或强制下载。

## 10. 测试矩阵

### 单元/组件

- Zod schema、格式化、权限视图、编辑器转换；
- ContentCard、CommentThread、UploadItem 的各种状态。

### E2E P0

1. 注册 → 验证 → 登录；
2. 新建项目 → 上传封面/附件 → 发布 → 搜索可见；
3. 评论/点赞/收藏/关注及刷新后状态；
4. 作者编辑与版本冲突；
5. 举报 → 管理员下架 → 审计记录；
6. 令牌过期刷新、退出全部设备；
7. 手机视口完成发布和互动。

### 视觉回归

首页、详情、编辑器、用户主页、后台举报页覆盖桌面/移动和亮/暗主题。

## 11. 前端交付顺序

1. Design Token、基础组件、Shell、错误页；
2. API 客户端、认证守卫、Query 基础设施；
3. 首页/发现/详情/用户主页；
4. 编辑器、上传队列、发布流程；
5. 评论互动与通知；
6. 设置和后台；
7. SEO、性能、无障碍与 E2E 收口。
